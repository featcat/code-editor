# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2025-11-21

### Added
- Initial release of CodeEditor component
- Monaco Editor integration with VSCode theming
- Language Server Protocol (LSP) support via WebSocket
- Multi-language support (JavaScript, TypeScript, Python, Go, Rust, JSON)
- Code execution capabilities with streaming support
- Real-time syntax highlighting and IntelliSense
- Customizable themes (Dark/Light mode)
- JSON editor for configuration
- Runner controls with output display
- Settings drawer for LSP and runner configuration

### Features
- Responsive design that fills parent container
- Language switching capability
- Code change callbacks
- Parameter configuration for code execution
- CSS modules for scoped styling
